# Sketch Manifest

## Design Direction
StrengthLog-like: familiar muscle-group-first browsing married to a fast search bar, on the app's existing dark-only token system (theme.ts). Core action to optimize: find any exercise in under 3 seconds, in the gym, one-handed. Redesign motivated by Phase 1 device UAT GAP-4 — the shipped search+chips+flat-list library was judged unintuitive.

## Reference Points
- StrengthLog (overall library layout, muscle-group browse, search+filter bar)
- Existing app tokens: theme.ts (dark-only, #0B0E11 bg, #4F8EF7 accent)
- Fixed taxonomy: constants/taxonomy.ts (10 muscle groups, 8 equipment types)
