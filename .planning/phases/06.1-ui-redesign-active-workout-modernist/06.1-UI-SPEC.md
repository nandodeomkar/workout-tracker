# Phase 06.1 — UI Design Contract

> Visual and interaction contract for the Modernist rebuild of the active-workout screen. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Source of truth:** `docs/design/active-workout/prototype.dc.html` (recreate its visual output in React Native + StyleSheet, dark-only) + `modernist-readme.md`. All BEHAVIOR already exists in code — this is a re-skin + two presentation modes over the existing logging engine (see Reuse Map in `06.1-CONTEXT.md`). ## Design System

| Property | Value |
|----------|-------|

**New dependencies the planner must add (flag):**

**Font loading approach:** load the four Archivo families in `app/_layout.tsx` with `useFonts({...})`; gate first render on the loaded flag (or `SplashScreen.preventAutoHideAsync()` → `hideAsync()` on load). Because RN applies custom fonts by family name (not numeric `fontWeight`), **weight is encoded in the family name** — each typography token below carries an explicit `fontFamily`; `fontWeight` is cosmetic only and should match for platform fallback.

## Typography (Archivo)

Load four families; encode weight in `fontFamily`. Roles below are lifted from the prototype (CONTEXT's role table references 700 for value/list text, so 700 is loaded alongside 400/600/800).

| Role | Size | Family / weight | Line height | Treatment |
|------|------|-----------------|-------------|-----------|
| `display` (giant numbers: Focus weight/reps, keypad value) | 46px (keypad 40px) | ExtraBold 800 | 0.9 | `fontVariant: ['tabular-nums']` |
| `heading` (screen/section titles, Focus exercise name, finish/discard titles) | 30px | ExtraBold 800 | 1.02–1.05 | `letterSpacing: -0.02em` (≈ -0.6px @30) |
| `exerciseName` (Instrument card title) | 18px | ExtraBold 800 | tight | `letterSpacing: -0.01em`, single-line ellipsis |
| `title` (sheet titles, list item names) | 15px | Bold 700 / ExtraBold 800 | normal | uppercase for sheet chrome titles |
| `setGridNumber` (Set/Kg/Reps values) | 19px | ExtraBold 800 | — | `tabular-nums` |
| `value` (row set #, meta values, keypad keys, list names) | 13–15px | Bold 700 | — | `tabular-nums` where numeric |
| `label` / kicker | 9.5–10px | SemiBold 600 | — | `letterSpacing: 0.1em`, `textTransform: 'uppercase'`, color `textDim`/`textMuted` |
| `body` (muted meta, discard body) | 11–13px | Regular 400 | 1.5 (discard body) | color `textMuted`/`textDim` |
| `unitSuffix` | 11–13px | Regular 400 | — | color `textDim`, trails the value |

`letterSpacing` in RN is in px — convert the em values against their font size (e.g. `.1em` at 10px = `1.0`; `-0.02em` at 30px = `-0.6`). Uppercase via `textTransform: 'uppercase'` (supported in RN Text).

Extend `theme.typography` (do not just revalue): keep `title/body/caption/display` resolvable for untouched screens; **add** `label`/kicker, per-role `fontFamily`, `letterSpacing`, and the big-display sizes. Existing screens inherit Archivo automatically once families are threaded into the retained keys.

## Interaction States (per Modernist readme)

RN has no `:hover`/`:focus-visible`; translate as:
- **Press (accent surfaces):** solid accent fills → `accentHover` `#ff563c` on press (`Pressable` pressed style / `android_ripple` color accent). Prototype uses `#ff563c` uniformly for the "hover" of solid accent buttons — follow the prototype (not the readme's dark-ramp accent-400) for solid fills.
- **Press (ghost/outlined):** outlined controls (steppers, Add-exercise, keypad step keys) → border + text/icon shift to `accent` on press; optional very-low-alpha accent bg tint.
- **Press (text actions):** muted text actions (Discard, rest ±15) → shift to `accent`/ink on press.
- **Focus-visible equivalent:** the current-set left rail and the Focus current-segment accent ring stand in for keyboard focus; no browser focus ring. For accessibility, keep 44×44 min touch targets (already honored by existing handlers/components).
- **Disabled:** reduce to ~45% opacity (readme), no color change.
- **Animations:** `prflash` (PR star), `restpulse` (rest countdown), `sheetup` (sheet entry) via `react-native-reanimated` (already a dependency); keep subtle, respect reduce-motion if trivial.

## Mode-state contract (`viewMode`)

- New ephemeral axis `viewMode: 'instrument' | 'focus'`, **default `instrument`**, orthogonal to the store's existing `mode: 'logging' | 'editing'` (do not conflate).
- Lives in ephemeral session state: recommend a **new Zustand field** on `useActiveWorkout` (so the choice survives minimize→resume within a live session) — **never persisted to SQLite**, never given `persist` middleware. Local `useState` is acceptable if the planner prefers reset-on-remount. Either way: not a DB column, no migration.
- `focusExId` (which exercise Focus targets) is also ephemeral local/store state; defaults to the first exercise with pending sets.
