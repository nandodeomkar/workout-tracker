# Phase 06.1 Plan 01: Global theme.ts Modernist Token Rewrite Summary

**Revalued and extended theme.ts to the dark Modernist rendition (background #131211, accent #ec3013, zero radius, Archivo typography) while preserving every existing export key so all 47 consumer files keep compiling unchanged.**

## Performance

- **Duration:** 12 min
- **Started:** 2026-07-27T10:03:00Z
- **Completed:** 2026-07-27T10:15:42Z
- **Tasks:** 2 completed
- **Files modified:** 1 (theme.ts)

## Accomplishments
- Revalued `theme.colors` to the dark Modernist palette (background/surface/surfaceAlt/text/textMuted/accent/border) and added four new keys (`textDim`, `accentHover`, `divider`, `dividerHairline`)
- Unified `danger` and `badge` to accent red `#ec3013` (deliberate mono-scheme change, D-04) across all consumers
- Set `theme.radius` to zero everywhere (`sm`/`md`/`lg` all `0`)
- Extended `theme.typography` with Archivo `fontFamily` strings on every existing role (`title`/`body`/`caption`/`display`) without changing their `fontSize`/`fontWeight`/`lineHeight`
- Added two new typography roles: `label` (uppercase kicker, 10px SemiBold, letterSpacing 1) and `heading` (30px ExtraBold, letterSpacing -0.6)
- Verified with `npx tsc --noEmit` (zero errors) — proves no consumer file references a removed token key

## Decisions Made
- `surfaceAlt` implemented as a flattened hex (`#242220`) rather than a ground+overlay composite — matches RESEARCH.md's stated discretion and the UI-SPEC's note that this is the "flattened equivalent" of `rgba(245,242,239,0.05)` on the new ground.
- `border` set equal to the new `divider` value so every existing hairline border across the app automatically reads Modernist without per-screen changes.
- danger/badge → accent unification confirmed to touch 12 non-active-workout `.tsx` files via grep (`app/programs/[programId].tsx`, `app/active-workout/summary.tsx`, `app/programs/new.tsx`, `components/TemplateBuilderForm.tsx`, `app/_layout.tsx`, `app/measurements/entry.tsx`, `app/(tabs)/exercises/[id].tsx`, `app/active-workout/[workoutId].tsx`, `components/SetRow.tsx`, `app/(tabs)/history/[workoutId].tsx`, `app/(tabs)/exercises/new.tsx`, `components/ExerciseRow.tsx`) — consistent with RESEARCH.md's "14 sites" estimate (some sites reference both keys in one file). This is expected and intentional per D-04; a visual regression walk across these screens is deferred to Plan 09 per the plan's own verification note.
