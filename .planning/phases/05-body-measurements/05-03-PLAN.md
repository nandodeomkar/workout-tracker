## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| keypad numeric entry → db write | quick-weigh-in value crosses into a persisted reading via upsertReadingForDate |
| history-row delete → db write | destructive action removes a persisted reading |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering | quick weigh-in value | medium | mitigate | Value flows through displayToKg then upsertReadingForDate, which calls assertValidMeasurementValue (Plan 02) — screen never writes an unvalidated number |
| T-05-05 | Tampering (data integrity) | same-day re-weigh-in | low | mitigate | upsertReadingForDate updates the existing today row rather than appending a duplicate; delete-with-confirm (D-09) removes bad rows |
| T-05-07 | Repudiation/Denial | destructive delete misfire | low | mitigate | Delete gated behind Alert.alert destructive confirmation before deleteReading runs |
| T-05-SC | Tampering (supply chain) | npm install surface | low | accept | No packages installed this phase (victory-native/Skia already present from Phase 4) |

No `high`-severity threats — nothing blocks per `security_block_on: high`.
</threat_model>
