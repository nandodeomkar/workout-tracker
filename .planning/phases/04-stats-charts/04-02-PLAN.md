<objective>
Deliver the first end-to-end vertical slice of Phase 4: a working per-exercise progress chart. After this plan, a user opens an exercise from the library, taps "View progress", and sees a real Skia line chart of that exercise's estimated-1RM over time, switchable to Top Set / Volume and filterable by 3M / 1Y / All. Purpose: Prove the whole chart stack (pure reduction → parameterized query → victory-native XL CartesianChart) against real logged data, reusing the existing e1RM/volume formulas verbatim (D-17).
Output: `lib/chartSeries.ts` (+test), `db/stats.ts` (new query module, +query test), a reusable `MetricToggle`, the `app/stats/[exerciseId].tsx` chart screen, and the "View progress" entry point on the exercise detail screen.
</objective>

**As a** lifter who logs workouts, **I want to** see per-exercise progress charts, weekly volume by muscle group, and a live PR feed, **so that** I can tell whether my training is actually working.
