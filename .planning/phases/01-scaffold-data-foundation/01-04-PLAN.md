## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User search/filter input → in-memory pipeline | Free-text search string handled in JS (no SQL round-trip), never concatenated into a query |
| SQLite read → UI | Read-only load of archived-visible exercises |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-04 | Tampering | `db/exercises.ts` read query | mitigate | Drizzle parameterized `.where(eq(...))`; search string is filtered in memory (never interpolated into SQL), eliminating any injection path from the search box |
| T-1-08 | Information Disclosure | archived exercises | accept | Archived rows are intentionally excluded from the default list (D-11) but remain readable via an explicit reveal toggle (Plan 05); single-user local device, no cross-tenant exposure |
</threat_model>
